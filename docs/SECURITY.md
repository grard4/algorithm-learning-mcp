# 安全与隐私

推荐本地 stdio。Streamable HTTP 默认监听 `127.0.0.1`；服务器不提供身份认证、租户隔离或远程访问授权。不要直接暴露到公网，不要让无关学习者共用数据库，不支持未经验证的网络文件系统多写入。

仅同一学习者、同一受信任主机的 Agent 可以共用本地数据库；这些 Agent 具有服务授予的读写能力。聊天内容和工具输出会由客户端按其设置处理，本服务器不控制模型厂商的数据政策。

私人偏好、数据库、归档、备份、同步日志、环境文件和本地审计材料均不得提交。发布只包含源码和通用模板，不包含 `.venv` 或学习数据。

发现疑似秘密泄露时先停止发布；检查暂存区与历史对象，不以删除当前文件冒充历史已清理。报告漏洞时只提供脱敏复现，不公开密钥、私人聊天或数据库。

最新扫描范围与局限见 `evidence/final-security-audit.md`，客户端测试边界见 TEST_REPORT.md。规则扫描不能证明不存在未知秘密，也不等于完整渗透测试。
