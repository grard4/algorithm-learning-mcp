# 安全与隐私

推荐本地 stdio。Streamable HTTP 默认监听 `127.0.0.1`；服务器不提供身份认证、租户隔离或远程访问授权。不要直接暴露到公网，不要让无关学习者共用数据库，不支持未经验证的网络文件系统多写入。

仅同一学习者、同一受信任主机的 Agent 可以共用本地数据库；这些 Agent 具有服务授予的读写能力。聊天内容和工具输出会由客户端按其设置处理，本服务器不控制模型厂商的数据政策。

私人偏好、数据库、归档、备份、同步日志、环境文件和本地审计材料均不得提交。发布只包含源码和通用模板，不包含 `.venv` 或学习数据。

发现疑似秘密泄露时先停止发布；检查暂存区与历史对象，不以删除当前文件冒充历史已清理。报告漏洞时只提供脱敏复现，不公开密钥、私人聊天或数据库。

首次发布时的历史扫描范围见 `evidence/final-security-audit.md`；当前源码验收边界见 [发布准备](../RELEASE_READINESS.md)，客户端历史测试见 [测试报告](TEST_REPORT.md)。规则扫描不能证明不存在未知秘密，也不等于完整渗透测试。
# 2026-11-27 安全审计修订

独立代码复核及修复状态见 ../AUDIT_FINDINGS.md 和 ../RELEASE_READINESS.md；此前发布隐私扫描不代表本轮安全回归。

HTTP 入口只接受回环地址（127.0.0.1、::1、localhost）；非回环配置报 UNSAFE_HTTP_BIND 并停止启动。本地 stdio 和回环 HTTP 保持原使用方式。SDK 1.30 默认提供请求体和会话数量限制，但本服务没有用户级速率配额、内置身份认证、细粒度授权或租户隔离。

远程单用户访问应使用由系统 SSH 服务认证的端口转发到回环端口，并限制 SSH 账号权限。不要将回环端口通过无认证代理公开；隧道用户拥有整个学习库的读写权限。隧道认证失败由 SSH 服务拒绝，当前项目不把 actor 或 conversation_id 当作登录凭据。SSH 部署本轮未实测，记为待验证；直接远程绑定及多用户托管不受支持。

内置课程规则不受私人偏好配置影响，但不是身份认证、文件访问控制或对外部模型行为的强制约束。拥有源码写权限的人仍可改代码；服务不保存完整课程文件，不能声称存在无法绕过的排版校验。详见 [规则边界](COURSE_RULES.md)。
