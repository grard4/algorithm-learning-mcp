## 环境与配置要求

服务端需要 Python 3.11+、本地 SQLite 和独立的 ALGORITHM_KB、ALGORITHM_PREFERENCES。客户端支持的 stdio/HTTP 配置方式、文件位置及版本适用范围须按其可访问的官方文档确认。所有客户端使用同一个 server.py，不另外维护服务器源码。

## 验证流程

配置完成后依次验证初始化（确认完整固定规则）、tools/list（默认 22 工具）、get_course_rules（核对版本 `2`、哈希与正文）、get_learning_preferences、临时数据库注册/读取、带证据的 update_learning 和重启后持久化。服务器读取偏好文件不证明客户端自身具有本地文件访问能力。

出现错误时检查解释器绝对路径、运行依赖、客户端支持版本、服务器标准错误与正常审批流程。不要降低安全策略，也不要用连接成功代替实际工具调用。未取得官方配置细节和真实客户端结果前，本页仅为待验证入口。
